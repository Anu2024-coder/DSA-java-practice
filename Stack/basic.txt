Stacks : Introduction: List and Array representations, Operations on stack (traversal, push and pop),
Arithmetic expressions: polish notation, evaluation and transformation of expressions. 
1. Stack – Introduction

A Stack is a linear data structure that follows the principle:

LIFO – Last In, First Out

🔹 The element inserted last is removed first
🔹 Operations are performed only from one end, called the TOP

2. Stack Representations
(A) Stack using Array Representation

📌 Uses a fixed-size array

Components:

arr[] → array

top → index of the top element (initially -1)

(B) Stack using Linked List Representation

📌 Uses nodes instead of array

Each node contains:

Data

Pointer to next node

Top points to the first node

3. Operations on Stack
(1) Push (Insertion)

Adds an element at the top

Steps:

Check overflow

Increment top

Insert element

(2) Pop (Deletion)

Removes element from the top

Steps:

Check underflow

Remove element

Decrement top


(3) Traversal

Displays elements from top to bottom

4. Arithmetic Expressions
Types of Notations
Notation	                Example
Infix	                    A + B
Prefix (Polish)	            + A B
Postfix (Reverse Polish)	A B +
