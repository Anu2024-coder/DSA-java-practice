----A Linked List -  is a dynamic linear data structure in which elements (nodes) are not stored in contiguous memory locations.
Each node contains:
1 Data part
2 Link (pointer) to the next node

----Types of Linked Lists-
1 Singly Linked List
2 Doubly (Two-way) Linked List
3 Circular Linked List
4 Header Linked List

----Each node is stored at any free memory location and linked using pointers.

----Nodes are connected using addresses, not physical order
----Last node points to NULL

----Memory is allocated dynamically at runtime.

----Traversal of Linked List

----Traversal means visiting each node exactly once.
----Algorithm:
1 Start from head
2 Print data
3 Move to next
4 Stop when NULL is reached
- Time Complexity:O(n)

----Insertion in Linked List
(a) Insertion at Beginning
Steps:
1 Create new node
2 Set newNode.next = head
3 Update head = newNode
- Time: O(1)

(b) Insertion at End
Steps:
1 Traverse till last node
2 Set last.next = newNode
3 newNode.next = NULL
- Time: O(n)

(c) Insertion at Specific Position
Steps:
1 Traverse till position-1
2 Adjust pointers
- Time: O(n)


Deletion in Linked List
(a) Deletion at Beginning
Steps:
1 head = head.next
- Time: O(1)

(b) Deletion at End
Steps:
1 Traverse to second last node
2 Set secondLast.next = NULL
- Time: O(n)

(c) Deletion of Specific Node
Steps:
1 Search element
2 Adjust links
- Time: O(n)


----A Header Linked List - contains a special header node that does not store actual data.
----Types:
1 Grounded Header List – Last node points to NULL
2 Circular Header List – Last node points to header

----A Grounded Linked List - is a normal linked list where:
Last node points to NULL


----In a Circular Linked List: Last node points to first node
No NULL pointers
--Useful in:
1 Round-robin scheduling
2 Circular queues


----Two-Way (Doubly) Linked List - Each node has three parts:
1 Previous pointer
2 Data
3 Next pointer
